How it works

Balls roll diagonally down the pegboard, one at a time. Each part decides which way the ball goes next. When a ball reaches a trigger it lands in the output tray and the next ball of the trigger's color is released.

  • Ramp sends the ball the way it slopes.
  • Crossover lets the ball keep going the same way.
  • Bit flips every time a ball passes, then sends the ball the way it now points. Left is 0, right is 1.
  • Gear bit works like a bit, and every gear bit linked to it through gears flips with it.
  • Gear links gear bits. Gears mesh with the parts directly above, below, left and right of them. They fit on any peg; everything else goes on the square pegs.
  • Interceptor catches the ball and ends the run.
  • Ejector releases balls of one color. Each color has one ejector; add as many colors as you like with + Ball color. Click an ejector with the Select tool to change which way it releases.
  • Trigger collects a ball and releases the next ball of the trigger's color. Place as many as you like. Click one with the Select tool to change its color.

Pick the color for new ejectors and triggers under the parts, or press C to cycle through colors. A ball that lands on an empty peg falls straight down to the next part below it. If nothing is below, it falls off the board and the run stops.

Registers. Pick the Register tool (9), then click bits, gear bits or ramps one at a time, or drag a box around several. A ramp counts as 1 when it points right and 0 when it points left, so ramps work as fixed values, like a constant to add. Press Make register. Its value shows on the board and in the Registers panel and updates live as balls flip the bits. The first bit you pick is the 1s place, the next is the 2s place, and so on. In a box, the top bit comes first. To set a register, type a number in its value box and press Enter. Decimal works, and so do 0b101 and 0x1F.

  • Place: pick a part, click a peg. Drag to paint many. Click a placed part with the same tool, or press F, to flip it.
  • Select tool (V): click a part to flip it, drag a part to move it. Drag a box over empty space to select many parts; Shift adds to the selection.
  • Labels: path and register labels fade when your pointer is over them so you can see the parts underneath. Drag one with the Select tool to move it.
  • Notes (N): pick the Note tool, then click to add a sticky note, or drag a box to draw a titled frame around part of a build. Click a note with the Note tool, or double-click it with the Select tool, to edit it and pick its color. Drag a frame by its title to move it with everything inside. Drag the corner square of a selected note or frame to resize it. The Notes button lists every note and frame; click one to jump to it. Hide notes (Shift+N) hides every note, frame and path until you show them again; they stay saved.
  • Paths (T): pick the Trace tool and click a square peg or an ejector to trace the route a ball would take from there. Click the left half of a peg for a ball rolling right, the right half for one rolling left. The line follows the board as it is now, so it changes as bits flip, and its label says where the ball ends up. Name it to explain what it shows. Drag a path's label to move it out of the way; a dotted line keeps it tied to its start. To stop a path partway down, drag its end point up (with the path selected or the Trace tool), or type a number of rows in Stop after while editing it. To join paths, select them (Shift-click) and press Merge paths: a path can continue one that ends where it starts, one that rolls through its start, or one whose trigger releases its ejector. Merged paths share bit flips, so the later ball sees the bits the earlier one left behind. During a run, Pin path saves the route the current or last ball really took.
  • With a selection: drag any selected part to move them all, or use the arrow keys. Ctrl+C copies, Ctrl+X cuts, Ctrl+V pastes (click to drop it), Ctrl+D duplicates, M mirrors left to right, Delete removes. Ctrl+A selects everything. Registers inside the selection are copied with it.
  • Erase: right-click or right-drag, or use the Eraser (E).
  • Move around: use the Pan tool (P), hold Space and drag, middle-drag, or pinch. Scroll to zoom. H fits the board.
  • Pieces: switch between Simple icons and Classic pieces that look like the physical game's parts.
  • Sound: in Classic, parts click and clack as balls pass. Use the Sound button to turn it off.
  • Board: pick a light or dark board, or Auto to match the page. This works with either piece style.
  • Run: Enter runs or pauses. Ctrl+Z undoes. Ctrl+S downloads the board as a .tti file.
